 # launch.sh — Job Orchestrator Wrapper 
 Submitted to Slurm with sbatch launch.sh, this wrapper connects Slurm’s resource allocation with PyTorch and NCCL to start distributed training. <br>Key mechanisms 
 <br><br>• Slurm directives (#SBATCH): Reserve the requested nodes, tasks, and GPUs before execution. <br>• Automated safety gate: Runs ./gpu_health.sh at job start and aborts if critical hardware anomalies are found. <br>• Environment mapping: Resolves the master-node address and coordination port dynamically. <br>• Distributed launcher: Uses srun and torchrun to start synchronized worker processes across the allocated GPUs. <br><br>Operational note: ensure that the Slurm task layout and the torchrun worker count are configured consistently to avoid accidentally launching duplicate workers.
