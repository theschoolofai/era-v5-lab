## How to fill it

1. Add one row for each problem found in a public data source.
2. If a source had no problems, still give it a row and write `none found` under Problem.
3. Under Evidence, link to the pull request or file that shows the problem, or its fix if the fix is done.

## Rules

- Write only about work that is done.
- Write `[number: waiting for TSAI]` in place of any number that TSAI has not approved.
- Name teams, never people.
- Name only public data sources.
- Do not quote text from the data. Never include personal data, secrets or internal links.
- Leave out cleaning methods and licences. They have their own sections in the model card.
- Do not use dashes.

**Evidence** must be a public pull request or a file in the lab repository on GitHub. Mark an open pull request as `(open)`. Never link to the CAP chat.
