## The fifteen runs

The command above is the run for 1e-4, seed 1234. The other fourteen runs use the same command. Only `--config`, `--seed`, and `--out` change. One fresh output directory per run. Do not pass `--smoke`. Do not pass `configs/small/smoke_resolution.yaml`.

| Arm | Config | Seeds | Output directory |
|---|---|---|---|
| exp1-lr-1e-4 | configs/arms/exp1/lr_1e-4.yaml | 1234, 1235, 1236 | ./out/exp1-lr-1e-4-<seed> |
| exp1-lr-3e-4 | configs/arms/exp1/lr_3e-4.yaml | 1234, 1235, 1236 | ./out/exp1-lr-3e-4-<seed> |

| exp1-lr-1e-2 | configs/arms/exp1/lr_1e-2.yaml | 1234, 1235, 1236 | ./out/exp1-lr-1e-2-<seed> |

Each run is T1: 245 steps, batch 8, 8192 tokens per step, 30 minutes. A run that stops before 245 steps is not a result. A logged NaN or inf voids that run. Max time 450 is 15 runs at 30 minutes each.

## Inputs TSAI publishes with this run

This request does not invent a sha256 and does not set `approval.status`.

- `./inputs/train.jsonl` and `./inputs/heldout.jsonl`, with the sha256 TSAI publishes. The two files must not be identical, and no document may appear in both.
- `./inputs/tokenizer_v0.json` from `teams/03-tokenizer/v0`.
- `./inputs/resolution.yaml`, the agreed resolution. A quality run stops until `approval.status` is agreed, `approval.reference` is set, and `evaluation.approved` is true. Those fields are still pending on main.
- `./inputs/heldout_sources.jsonl`, `./inputs/heldout.sha256`, and `./inputs/heldout_report.json`. The trainer requires them for a run that is not smoke. The held-out file must contain all 15 slices: en, code, math, sci, hi, bn, ta, te, kn, ml, mr, gu, pa, or, as. The report must record 0 matches for the published held-out sha256.

The byte table is already on main: `teams/04-ke2/results/tables/raw_table_P32.npz`.
