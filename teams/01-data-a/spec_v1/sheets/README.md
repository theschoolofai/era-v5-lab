[specv1.md](specv1.md) is the reviewed consolidated input consumed by [build_clean.py](../tools/build_clean.py). The build reads this consolidated file; it does not automatically collect changed family sheets. Indic integration refreshes its own consolidated cards through the separately documented review process. English source compilation has an outstanding reproduction dependency described in [the English guide](../tools/README_english.md#removed-legacy-files).

The former code/English overview documents were removed during cleanup. Use this index, the family decisions, and [the spec guide](../README.md). Review status and historical harm evidence remain subject to their recorded pack, gold, and code snapshots.
