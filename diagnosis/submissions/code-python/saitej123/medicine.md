## Medicine 1

1. **Disease:** `B3` (ghost dataset markers), count `272`. Examples: `0d1e11b4c0740741` (`dataset marker <gh_stars> at offset 0`), `5e467bb5ce89997f` (`dataset marker <reponame> at offset 0`), `680d4363d4d1bd8e` (`dataset marker <gh_stars> at offset 0`).
2. **Medicine:** delete a StarCoder header tag and the text that belongs to it. The tags are `<reponame>`, `<filename>`, and `<gh_stars>`. ChatML markers do not occur in this pack.
```python
import re

def medicine_b3(text: str) -> str:
    text = re.sub(r"<reponame>[^\n]*\n?", "", text)
    text = re.sub(r"<filename>[^\n<]*", "", text)
    text = re.sub(r"<gh_stars>[^\n<]*", "", text)
    return text
```
3. **Action:** fix the text.
4. **Harm test:** 164 pack documents with no disease — `0` changed, `0` dropped. Pass (`<= 1%`).
5. **Side effects:** a source string that contains one of these tags as literal text loses that tag.

## Medicine 3

1. **Disease:** `E1` (generated file), count `8`. Examples: `fcab84d53c43cbf9` (`auto-generated header at offset 0`), `482d33373cdb5a6c` (`auto-generated header at offset 0`), `4280e8634129c11b` (`auto-generated header at offset 269`).
2. **Medicine:** drop the document when the file itself says it was generated and must not be edited: a line `# Generated by Django` plus a version digit, the AutoRest line `Code generated by Microsoft (R) AutoRest Code Generator`, or a line `# Generated file, DO NOT EDIT`.
```python
import re

E1_DROP = re.compile(
    r"(?m)(?:^# Generated by Django \d|"
    r"Code generated by Microsoft \(R\) AutoRest Code Generator|"
    r"^# Generated file, DO NOT EDIT)"
)

def medicine_e1(text: str) -> str | None:
    return None if E1_DROP.search(text) else text
```
3. **Action:** drop the document.
4. **Harm test:** 164 pack documents with no disease — `0` changed, `0` dropped. Pass (`<= 1%`).
5. **Side effects:** a hand-written file whose first line is exactly `# Generated by Django` plus a version digit would be dropped.
