## Medicine 3

1. **Disease:** `E1` (generated file), count `11`. Examples: `21` (`auto-generated header at offset 101`), `126` (`auto-generated header at offset 253`), `190` (`auto-generated header at offset 36`).
2. **Medicine:** drop the document when the file itself says it was generated and must not be edited: a line `# Generated by Django` plus a version digit, the AutoRest line `Code generated by Microsoft (R) AutoRest Code Generator`, or a line `# Generated file, DO NOT EDIT`. A Colab export header, a `django-admin startproject` settings comment, and the word "generated" inside a string are not this pattern.
```python
import re

E1_DROP = re.compile(
    r"(?m)(?:^# Generated by Django \d|"
    r"Code generated by Microsoft \(R\) AutoRest Code Generator|"
    r"^# Generated file, DO NOT EDIT)"
)

def medicine_e1(text: str) -> str | None:
    return None if E1_DROP.search(text) else text
```
3. **Action:** drop the document.
4. **Harm test:** 200 pack documents with no labelled disease — `0` changed, `0` dropped. Pass (`<= 1%`).
5. **Side effects:** a hand-written file whose first line is exactly `# Generated by Django` plus a version digit would be dropped.
