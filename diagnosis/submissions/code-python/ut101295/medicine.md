# Medicine sheet: code-python (ut101295)

Pack: `code-python` (500 documents from `bigcode/starcoderdata`). One section for each disease found more than five times.
Order of the sections is the order to apply them: the drop rule first, then the fixes.

Harm test: `teams/01-data-a/tools/harm_test.py` on the code-python gold set (`teams/01-data-a/gold/code-python_gold.csv`, 141 documents marked clean by two readers). Limit: max(1, 1% of 141) = 1 document per rule.

## Medicine 1

1. **Disease:** E1 (generated code). Count: 12 of 500. Examples:
   - `fcab84d53c43cbf9`: `Generated by Django 3.1.2` at offset 2 (Django migration)
   - `6359488cb66a0aa6`: `this file was generated by the Pulumi Terraform Bridge` at offset 98
   - `4280e8634129c11b`: `Code generated by Microsoft (R) AutoRest Code Generator` at offset 269
2. **Medicine:** drop a file when its first 3000 characters carry the marker of a code generator: Django migrations, Azure AutoRest, Pulumi SDK generators, the protocol buffer compiler, the KBase type compiler, `@generated`, or a top comment/docstring that says "autogenerated". Templates that people are meant to edit (for example `Generated by 'django-admin startproject'`) are not matched.

   ```python
   import re

   _E1_MARKER = re.compile(
       r"(?i)generated by django \d"
       r"|code generated by microsoft \(r\) autorest"
       r"|this file was generated by the pulumi"
       r"|generated by the pulumi"
       r"|generated by the protocol buffer compiler"
       r"|autogenerated by the \w+ type compiler"
       r"|^\s*(?:#|\"\"\"|''')\s*[\w.-]*\s*auto-?generated\b"
       r"|@generated\b",
       re.M,
   )


   def medicine_e1(text):
       """Drop files whose first 3000 characters say a tool generated them."""
       return True if _E1_MARKER.search(text[:3000]) else text
   ```
3. **Action:** drop the document.
4. **Harm test:** gold set 141 documents: 0 changed, 0 dropped (0%). PASS. On the whole pack it drops exactly the 12 documents labelled E1 and no other document.
5. **Side effects:** a hand-written file that says "this file was generated by the Pulumi ..." in a comment would be dropped. Generators with other wording (Swagger, Thrift, SQLAlchemy codegen) are not caught; no such file is in this pack. Files that a tool starts and people then edit (Django `settings.py`, wxGlade GUIs with hand-written handlers) are kept on purpose.

## Medicine 2

1. **Disease:** B3, StarCoder metadata markers (`<reponame>`, `<filename>`, `<gh_stars>`, sometimes several on one line) at the top of a file. Count: 272 of 500. Examples:
   - `0d1e11b4c0740741`: `<gh_stars>0` at offset 0
   - `5e467bb5ce89997f`: `<reponame>themenucha/grpc` at offset 0
   - `f9b9d7808a2ff30b`: `<reponame>` at offset 0 (one line with `<reponame>` and `<filename>`)
2. **Medicine:** remove the metadata line(s) at the very start of the file.

   ```python
   import re

   _B3_HEADER = re.compile(r"\A(?:<(?:reponame|filename|gh_stars)>[^\n]*\n)+")


   def medicine_b3(text):
       """Remove the StarCoder metadata line(s) at the very top of the file."""
       return _B3_HEADER.sub("", text, count=1)
   ```
3. **Action:** fix the text.
4. **Harm test:** gold set 141 documents: 0 changed, 0 dropped (0%). PASS. On the whole pack it changes exactly the 272 documents labelled B3 and no other document.
5. **Side effects:** only the first line(s) of a file are touched, so a tag inside the code (for example a usage string `"Usage: java Benchmark <filename>"`) is kept. A file whose first real line starts with one of the three tags would lose that line; there is none in this pack.

## Medicine 3

1. **Disease:** B4, PII placeholders left by the earlier PII cleaning (`<NAME>`, `<EMAIL>`, `<PASSWORD>`, `<KEY>`; ruling 2). Count: 83 of 500. Examples:
   - `6a0b23e505a31093`: `<NAME>` at offset 177 (`__author__ = "<NAME>"`)
   - `717461624ebd2d57`: `<EMAIL>` at offset 530 (`TEST_ROOT_EMAIL = "<EMAIL>"`)
   - `4c5fc5660f257bd3`: `<EMAIL>` at offset 1373
2. **Medicine:** replace each placeholder with a fixed neutral word (`AUTHOR`, `user@example.com`, `EXAMPLE_PASSWORD`, `EXAMPLE_KEY`), so the model does not learn the placeholder tokens. A placeholder that stands as a bare Python value (`password=<PASSWORD>`, `SECRET_KEY = <KEY>`) gets quotes, so the file parses again.

   ```python
   import re

   _B4_PLACEHOLDER = re.compile(r"(['\"]?)<(NAME|EMAIL|PASSWORD|KEY|IP_ADDRESS|USERNAME)>(['\"]?)")
   _B4_NEUTRAL = {"NAME": "AUTHOR", "EMAIL": "user@example.com", "PASSWORD": "EXAMPLE_PASSWORD",
                  "KEY": "EXAMPLE_KEY", "IP_ADDRESS": "192.0.2.1", "USERNAME": "USERNAME"}


   def _b4_fill(m):
       q1, kind, q2 = m.groups()
       value = _B4_NEUTRAL[kind]
       if q1 or q2:
           return f"{q1}{value}{q2}"
       before = m.string[:m.start()].rstrip(" \t")[-1:]
       if before in "=([,":
           return f'"{value}"'
       return value


   def medicine_b4(text):
       """Replace PII placeholders with neutral words; a bare placeholder used as a value gets quotes."""
       return _B4_PLACEHOLDER.sub(_b4_fill, text)
   ```
3. **Action:** fix the text.
4. **Harm test:** gold set 141 documents: 0 changed, 0 dropped (0%). PASS. On the whole pack it changes exactly the 83 documents labelled B4 and no other document. No placeholder is left, no file that parsed stops parsing, and 7 files that a bare placeholder had broken (`password=<PASSWORD>`) parse again.
5. **Side effects:** the neutral word is not the true value (`Copyright 2016 AUTHOR`). A real `<NAME>` in code (for example a usage string `prog <NAME>`) would be replaced; there is none in this pack. A placeholder that replaced part of an expression stays wrong code (`os.<PASSWORD>.get` becomes `os.EXAMPLE_PASSWORD.get`).

## Medicine 4

1. **Disease:** E4 (repeated licence headers). Count: 115 of 500. Examples:
   - `5e467bb5ce89997f`: `# Copyright 2016, Google Inc.` at offset 51 (BSD, 28 lines)
   - `cc46017245578753`: `# Licensed under the Apache License, Version 2.0` at offset 78
   - `69bce9067cd2e646`: `# licensed under MIT, Please consult LICENSE.txt for details` at offset 134
2. **Medicine:** in the preamble of the file (the comment blocks and docstrings before the first line of code), remove each paragraph that is licence text: a paragraph with a strong licence phrase (copyright, licensed under, SPDX, permission is hereby granted, a licence URL and others), or with at least three different licence words (warranty, liability, licence, distribution, permission, merchantability, damages). Shebang, encoding and description paragraphs stay. Licence text after the first line of code is left alone.

   ```python
   import re

   _E4_STRONG = re.compile(
       r"(?i)copyright|spdx-license-identifier|licensed under|permission is hereby granted|all rights reserved"
       r"|redistribution and use in source|gnu (?:general|lesser|affero) public license|apache license|mit license"
       r"|bsd(?:-\d)? license|mozilla public license|(?:apache|opensource|gnu)\.org/licenses|licen[cs]e terms|^\s*:licen[cs]e:",
       re.M,
   )
   _E4_WEAK = re.compile(r"(?i)warrant|\bas is\b|liabilit|licen[cs]e|distribut|permission|merchantab|copyright|infring|damages")
   _E4_TOP = re.compile(r"#!|#.*coding[:=]|<(?:reponame|filename|gh_stars)>")
   _E4_HASH = re.compile(r"^\s*#+ ?")
   _E4_NONE = re.compile(r"^\s*")
   _E4_DOC_OPEN = re.compile(r"\s*[rRuU]?(\"{3}|'{3})")


   def _e4_is_licence(paragraph):
       words = {m.group(0).lower()[:6] for m in _E4_WEAK.finditer(paragraph)}
       return bool(_E4_STRONG.search(paragraph)) or len(words) >= 3


   def _e4_strip_paragraphs(block, prefix):
       blank = lambda ln: not prefix.sub("", ln).strip(" \t-=#*~")
       out, para, removed = [], [], []

       def flush():
           if para and _e4_is_licence("\n".join(prefix.sub("", ln) for ln in para)):
               removed.append(len(para))
           else:
               out.extend(para)
           para.clear()

       for ln in block:
           if blank(ln):
               flush()
               out.append(ln)
           else:
               para.append(ln)
       flush()
       if not removed:
           return block
       while out and blank(out[0]):
           out.pop(0)
       while out and blank(out[-1]):
           out.pop()
       return out


   def medicine_e4(text):
       """Remove licence paragraphs from the preamble (comment blocks and docstrings before the first code line)."""
       lines, out, i, changed = text.split("\n"), [], 0, False
       while i < len(lines) and i < 120:
           ln = lines[i]
           if not ln.strip() or _E4_TOP.match(ln):
               out.append(ln)
               i += 1
           elif ln.lstrip().startswith("#"):
               j = i
               while j < len(lines) and lines[j].lstrip().startswith("#"):
                   j += 1
               kept = _e4_strip_paragraphs(lines[i:j], _E4_HASH)
               changed |= len(kept) != j - i
               out.extend(kept)
               i = j
               if not kept:
                   while i < len(lines) and not lines[i].strip():
                       i += 1
           elif _E4_DOC_OPEN.match(ln):
               q = _E4_DOC_OPEN.match(ln).group(1)
               if ln.count(q) >= 2:
                   out.append(ln)
                   i += 1
                   continue
               j = next((n for n in range(i + 1, len(lines)) if q in lines[n]), None)
               if j is None:
                   break
               head, first = ln.split(q, 1)
               body = ([first] if first.strip() else []) + lines[i + 1:j]
               kept = _e4_strip_paragraphs(body, _E4_NONE)
               if len(kept) != len(body):
                   changed = True
                   out.append(head + q)
                   out.extend(kept)
               else:
                   out.extend(lines[i:j])
               out.append(lines[j])
               i = j + 1
           else:
               break
       return "\n".join(out + lines[i:]) if changed else text
   ```
3. **Action:** fix the text.
4. **Harm test:** gold set 141 documents: 0 changed, 0 dropped (0%). PASS. On the whole pack it changes 114 of the 115 documents labelled E4 and no other document; it removes 570 characters per file (median), 1615 at most. No file that parsed stops parsing.
5. **Side effects:** it misses licence text after the first line of code: `8f92de0e125970be` has its licence at line 812, after the code starts. A description paragraph that also uses three licence words ("distributed ... permission ... liability") would be removed with the licence. A one-line pointer such as `# See the LICENSE file ... of this distribution` is kept, because it has only two licence words: two readers marked such a file clean.

## Medicine 5

1. **Disease:** A2 (control characters): carriage returns from Windows line endings (CRLF). Count: 17 of 500. Examples:
   - `9942b8de5559f733`: U+000D at offset 25, 64 times
   - `951c0ffae8ed4db6`: U+000D at offset 84, 37 times
   - `aa4812f89a7ce665`: U+000D at offset 50, 31 times
2. **Medicine:** turn `\r\n` and a lone `\r` into `\n`, and remove the other C0 control characters. Tab, newline and form feed (valid Python whitespace) stay.

   ```python
   import re

   _A2_CONTROL = re.compile(r"[\x00-\x08\x0b\x0e-\x1f\x7f]")


   def medicine_a2(text):
       """Normalise line endings to \\n and remove other C0 control characters (keeps tab, newline, form feed)."""
       text = text.replace("\r\n", "\n").replace("\r", "\n")
       return _A2_CONTROL.sub("", text)
   ```
3. **Action:** fix the text.
4. **Harm test:** gold set 141 documents: 0 changed, 0 dropped (0%). PASS. On the whole pack it changes exactly the 17 documents labelled A2 and no other document.
5. **Side effects:** a string literal that needs a real `\r` character (not the two characters `\` `r`) would change; there is none in this pack. Control characters inside binary data pasted into a file would be removed; such a file should be dropped as E2 anyway.

## Not covered by a medicine

E3 (secrets, 3 documents), E2 (data blobs, 2) and E6 (not code, 1) were found five times or fewer. No medicine is proposed for them.

F2: none. Under the instructor's ruling of 30 Oct, a LeetCode, AtCoder or Baekjoon solution is not a benchmark leak unless the problem is an item of a known benchmark test set, named in the evidence.
