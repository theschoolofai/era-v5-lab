# Medicine sheet: ind-mr-fw2 (adinathauti)

Write one section for each disease that you found more than five times.

## Medicine 1

1. **Disease:** code, count in your pack, three examples (`doc_id` and the exact characters).
2. **Medicine:** the rule in words, and in code (a regex or a short Python function).
3. **Action:** fix the text, or drop the document.
4. **Harm test:** run the medicine on the gold set of your language. Give the number of gold documents that it changes and the number that it drops. A medicine that changes or drops more than 1% of the gold set fails.
5. **Side effects:** the cases where the medicine is wrong.
