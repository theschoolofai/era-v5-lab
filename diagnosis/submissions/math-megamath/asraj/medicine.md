# Medicine sheet: math-megamath (asraj)

Harm tests: `teams/01-data-a/tools/harm_test.py` on the real gold set `teams/01-data-a/gold/math-megamath_gold.csv` (26 documents). A rule passes when it changes or drops at most max(1, 1%) of the gold set, here 1 document. Each python block runs on its own: `medicine_<code>(text)` returns the new text, or `("drop", text)` to drop the document.

## Medicine 1: C1 (Boilerplate)

**Disease:** C1, 323 documents in my pack. Examples: `e6a35e0a1697811c` ('Ads by Google' @0 (ad header)); `d492cffdecdbee5e` ('## Answer This Question' @536 (Q&A template footer)); `51d28246c01896ca` ('Search the Dr. Math Library:' @3642 (site footer)).

**Medicine:** Cut site furniture: a known footer marker in the second half of the document and everything after it, and whole lines of forum chrome.

```python
import re
import unicodedata

_c1_C1_TAIL = re.compile(r"^(?:#+\s*)?(?:Answer This Question|More Related Questions|Related Questions|Similar Discussions|"
                     r"Similar Threads|Search the Dr\. Math Library|Prev by Date|Next by Date|"
                     r"Follow Math Help Forum|View Tag Cloud|Have something to add\?|More information about the|"
                     r"This archive was generated by|Topic archived\. No new replies allowed\.|Bookmarks|"
                     r"Ask Your Question|Weekly Poll)\b.*",
                     re.M | re.S)

_c1_C1_LINE = re.compile(r"^(?:Printable View|Originally Posted by.*|Reply With Quote|Dismiss Notice|Loading\.\.\.|"
                     r"You are not logged in\.?|Thank you for using the timer.*|Show Tags|Add Yours|"
                     r"Search All of the Math Forum:?.*)\s*$", re.M)

_c1_QA_FOOTER = re.compile(r"^#+\s*Answer This Question\s*$.*", re.M | re.S)

_c1_QA_POSTED = re.compile(r"^Posted by \*\*[^*\n]{1,60}\*\* on [A-Z][a-z]+day, [A-Z][a-z]+ \d{1,2}, \d{4} at \d{1,2}:\d{2}[ap]m\.?\s*\n", re.M)

_c1_QA_REPLY = re.compile(r"^\*\*[^*\n]{1,60}\*\*, [A-Z][a-z]+day, [A-Z][a-z]+ \d{1,2}, \d{4} at \d{1,2}:\d{2}[ap]m\s*$", re.M)

_c1_QA_TITLE = re.compile(r"^- [^\n]{1,80} -\s*$", re.M)

def _c1_med_QA(t):
    # only for pages with the Q&A footer; other documents come back unchanged
    m = _c1_QA_FOOTER.search(t)
    if not m:
        return t
    t = t[:m.start()]
    t = _c1_QA_POSTED.sub("", t)
    t = _c1_QA_REPLY.sub("", t)
    t = _c1_QA_TITLE.sub("", t)
    return re.sub(r"\n{3,}", "\n\n", t).strip() + "\n"

_c1_MF_HEADER = re.compile(r"\ASearch All of the Math Forum:\n(?:.*\n){0,20}?Posted:\n[^\n]*\n+")

def _c1_med_C1(t):
    t = _c1_med_QA(t)
    t = _c1_MF_HEADER.sub("", t)
    m = _c1_C1_TAIL.search(t)
    if m and m.start() > 0.5 * len(t):
        t = t[:m.start()].rstrip() + "\n"
    t2 = _c1_C1_LINE.sub("", t)
    return re.sub(r"\n{3,}", "\n\n", t2) if t2 != t else t

def medicine_c1(text):
    out = _c1_med_C1(text)
    return ("drop", text) if out is None else out
```

**Harm test:** changes 0 and drops 0 of 26 gold documents (limit 1): **PASS**.

**Side effects:** Misses most site chrome: it knows only listed markers, so headers and footers of sites not in the list (nLab context sidebars, GMAT Club timer banners, Mathigon menus, StatisticsHowTo 'CITE THIS AS' footers) stay. A tail marker is cut only in the second half of the document, so a footer on a very short page survives. Over-reach: a real line that is exactly a chrome phrase (a heading 'Bookmarks') would be cut. Measured on my pack: it acts on 70 of my 323 C1 documents (the rest are misses of the kinds above) and touches 1 documents I did not label C1.

## Medicine 2: B5 (Broken or stripped math)

**Disease:** B5, 186 documents in my pack. Examples: `fe174b7a4eefbe48` ('has the form  , (1)' @51 (equation deleted, number left)); `586c7b4c711cfd3f` ('The total electrical energy is then given in watt-hours, Wh:' @1609 (equation (image) stripped after colon)); `6134c52da8a58271` ('h \colonG \mapsto' @16808 (undefined macro \colonG)).

**Medicine:** Drop documents where the extractor stripped the math. Score = places where a lead-in word ('is', 'where', 'by', ...) is followed directly by punctuation, plus 2 for each line that is only an equation number ('  , (1)'). Drop at score 5 when it is 1+ per 1,000 characters, or at score 3 when it is 4+ per 1,000 characters (a short page with most of its math gone). A few gaps in a long document are a fix, not a drop.

```python
import re
import unicodedata

_b5_STRIPPED = re.compile(r"\b(?:is|are|be|by|as|that|where|then|get|gives?|form|equals?|have|has|obtain|becomes?|so|thus|"
                      r"hence|namely|denote|define[sd]?|write|solve|find|satisf(?:y|ies)|to|of|and|or|with|for|at|let|"
                      r"if|when|whence|follows?|yields?|reads?|holds?)[ \t]+[.,;:](?=\s|$)", re.I)

_b5_EQNUM = re.compile(r"^[ \t]*[.,;:]?[ \t]*\(\d{1,3}[a-z\']?\)[ \t]*$", re.M)

def _b5_b5_score(t):
    s = len(_b5_STRIPPED.findall(t)) + 2 * len(_b5_EQNUM.findall(t))
    density = s / max(0.5, len(t) / 1000)          # per 1,000 characters
    return s, density

def _b5_b5_drop(t):
    s, density = _b5_b5_score(t)
    # dense damage only: 5+ gaps at 1+ per 1,000 chars, or 3+ gaps in a short page (4+ per 1,000)
    return (s >= 5 and density >= 1) or (s >= 3 and density >= 4)

def _b5_med_B5(t):
    return None if _b5_b5_drop(t) else t

def medicine_b5(text):
    out = _b5_med_B5(text)
    return ("drop", text) if out is None else out
```

**Action:** drop.

**Harm test:** changes 0 and drops 0 of 26 gold documents (limit 1): **PASS**.

**Side effects:** Drop-only and conservative: it counts lead-in words followed by punctuation and bare equation numbers, so it misses pages whose displayed equations were images (sentences ending ':' then prose), stripped units ('less than , when'), and TeX broken in other ways. The gaps themselves cannot be repaired, so B5 documents below the threshold keep their gaps. Over-reach: prose that legitimately ends 'as follows.' near numbered lines can push a short page over the threshold. Measured on my pack: it acts on 7 of my 186 B5 documents (the rest are misses of the kinds above) and touches 0 documents I did not label B5; it drops 1 documents I labelled fix or clean.

## Medicine 3: C5 (Lists of links or teasers)

**Disease:** C5, 152 documents in my pack. Examples: `e6a35e0a1697811c` ('and the volume of a...## chemical analysis' @519 (teaser cut with ... and glued heading)); `d492cffdecdbee5e` ('- algebra - Could someone please help me with this?' @663 (related-question teasers)); `6de7ca51a59638cb` ('Move the pieces of the tower from one place to another in the minimum number of moves.' @495 (link blurb)).

**Medicine:** Cut every run of 3+ teaser lines (lines of 10+ characters that end cut off with '...' or '…'; blank lines inside a run are cut too). Bullet and numbered lists are never touched. Drop the document when less than 150 characters remain: then the list was the page.

```python
import re
import unicodedata

def _c5_med_C5(t):
    """Cut runs of 3+ teaser lines ('...'-cut; blank lines between them allowed);
    drop the document when under 150 characters of other text remain (the list was the page)."""
    lines = t.split("\n")
    bad = [len(l.strip()) >= 10 and l.rstrip().rstrip("|").rstrip().endswith(("...", "…")) for l in lines]
    out, i, cut = [], 0, False
    while i < len(lines):
        if bad[i]:
            j, k, n = i, i, 0
            while j < len(lines) and (bad[j] or not lines[j].strip()):
                if bad[j]: n += 1; k = j
                j += 1
            if n >= 3:
                cut = True; i = k + 1; continue
        out.append(lines[i]); i += 1
    if not cut:
        return t
    o = re.sub(r"\n{3,}", "\n\n", "\n".join(out))
    return None if len(re.sub(r"\s+", " ", o).strip()) < 150 else o

def medicine_c5(text):
    out = _c5_med_C5(text)
    return ("drop", text) if out is None else out
```

**Action:** fix (drop when the list was the page).

**Harm test:** changes 0 and drops 0 of 26 gold documents (limit 1): **PASS**.

**Side effects:** Cuts only teaser lines that end cut off with '...'/'…'; bullet link lists, tag clouds and 'related questions' lists without an ellipsis are missed (left to C1 or a human drop). Over-reach: a run of 3+ real lines that end in a deliberate ellipsis (a numeric pattern '1, 2, 3, ...' line by line) would be cut, and the 150-character drop rule removes very short Q&A pages whose only content is one line. Measured on my pack: it acts on 36 of my 152 C5 documents (the rest are misses of the kinds above) and touches 0 documents I did not label C5.

## Medicine 4: C2 (Repeated lines)

**Disease:** C2, 128 documents in my pack. Examples: `4239e909b40289e8` ('For a small fee you can get the industry’s best online privacy' @4940 (promo paragraph repeated 4x)); `cb56d0f3c6fa048a` ('**Re: Re: Weird result in Mathematica 6**' @4715 (nav title repeated)); `2ab919b65e15bf56` ('Tracy Migre, a certified public accounting, has completed the following transactions.' @2626 (same teaser 4x)).

**Medicine:** Remove exact repeats of a line of 30+ characters, keeping the first.

```python
import re
import unicodedata

def _c2_med_C2(t):
    seen, out, changed = set(), [], False
    for line in t.split("\n"):
        key = line.strip()
        if len(key) >= 30 and key in seen:
            changed = True
            continue
        seen.add(key); out.append(line)
    return "\n".join(out) if changed else t

def medicine_c2(text):
    out = _c2_med_C2(text)
    return ("drop", text) if out is None else out
```

**Action:** fix.

**Harm test:** changes 0 and drops 0 of 26 gold documents (limit 1): **PASS**.

**Side effects:** Works on exact repeated lines of 30+ characters only: a passage repeated with different line breaks, or a quoted post repeated with '> ' prefixes, is missed. Over-reach: it removes lines that legitimately repeat, such as a restated result in each step of a worked solution ('Number of Shares Owned = 57,142'), a repeated question stem, or the same equation shown twice in a derivation. Measured on my pack: it acts on 98 of my 128 C2 documents (the rest are misses of the kinds above) and touches 31 documents I did not label C2.

## Medicine 5: B2 (Glued markup / code lines)

**Disease:** B2, 106 documents in my pack. Examples: `51d28246c01896ca` ('Metric vs. Standard SystemDate:' @0 (title glued to header field)); `a97bd9875beb69dd` ('Dim totalInches As Doublemiles = CInt(txtMiles.Text)' @326 (code lines glued)); `d71c60e279f201ed` ('Let DEFG be a > rectangle' @255 (email quote markers mid-text)).

**Medicine:** Markup residue where line breaks were stripped. (a) Code lines glued together: insert the missing newline at a block keyword glued to the next statement ('End WithEnd Sub', '* 100With'), a type glued to the next assignment ('As Doublemiles ='), or ')' glued to the next assignment; LaTeX lines are skipped. (b) Email quote markers: on a line that starts with '> ', remove each '>' that has a space or line start before it, unless it sits between two math terms ('AB > 2*AD'); remove a trailing sign-off ('Best regards, Avni'). '>' on any other line is never touched.

```python
import re
import unicodedata

_b2_PATTERNS = [
    r"(?P<k>\bEnd (?:With|Sub|If|Function|Select|Class|Module|Property))(?=[A-Z][a-z])",       # End WithEnd Sub
    r"(?P<k>\bAs (?:Double|Integer|String|Long|Boolean|Single|Decimal|Object|Date))(?=[a-z]\w* ?=)",  # As Doublemiles =
    r"(?P<k>[\d)])(?=(?:With|Dim|Next|Loop|End|If|For|Return|Print)\b[ .])",                  # * 100With x.
    r"(?P<k>\))(?=[a-z]\w* = )",                                                               # (meters / 100)kilometers =
    r"(?P<k>[;}])(?=(?:int|double|float|var|let|const|return|for|while|if|public|private)\b )",  # ...;int x
]

_b2_CODE_GLUE = re.compile("|".join(f"(?:{p.replace('(?P<k>', f'(?P<k{i}>')})" for i, p in enumerate(_b2_PATTERNS)))

def _b2_glue_points(t):
    out = []
    for m in _b2_CODE_GLUE.finditer(t):
        k = next(g for g in m.groupdict() if m.group(g) is not None)
        p = m.end(k)
        line = t[t.rfind("\n", 0, p) + 1: (t.find("\n", p) if t.find("\n", p) != -1 else len(t))]
        if "\\" in line or "$" in line:
            continue                                   # LaTeX, not code: ')dxdydz =' is math
        out.append(p)
    return out

def _b2_split_code_glue(t):
    pts = _b2_glue_points(t)
    if not pts:
        return t
    parts, last = [], 0
    for p in pts:
        parts.append(t[last:p]); last = p
    parts.append(t[last:])
    return "\n".join(parts)

_b2_MATHTOK_L = re.compile(r"^(?:[A-Z0-9]{1,4}|[a-z]|\S*[)\]}])$")

_b2_MATHTOK_R = re.compile(r"^(?:[A-Z0-9(\-]|[a-z](?:[\s,.;)]|$))")

_b2_SIGNOFF = re.compile(r"(?:^|(?<=\s))(?:Best regards|Kind regards|Regards|Thanks|Thank you|Cheers)\s*,\s*(?:>\s*)?[A-Z][a-z]{1,20}\s*$")

def _b2_quote_markers(t):
    out = []
    for lm in re.finditer(r"^> [^\n]*", t, re.M):
        line, base = lm.group(0), lm.start()
        for m in re.finditer(r"(?:(?<=^)|(?<=\s))>(?=\s|>|$)", line):   # a marker is never glued to a word
            left = line[:m.start()].rstrip().split(" ")[-1] if line[:m.start()].strip() else ""
            right = line[m.end():].lstrip()
            if left and _b2_MATHTOK_L.search(left) and _b2_MATHTOK_R.search(right) and not right.startswith(">"):
                continue                                        # a comparison inside the quote: keep it
            out.append(base + m.start())
    return out

def _b2_strip_quote_markers(t):
    pts = set(_b2_quote_markers(t))
    if not pts:
        return t
    s = "".join(ch for i, ch in enumerate(t) if i not in pts)
    s = re.sub(r"(?m)^[ \t]+", "", re.sub(r"[ \t]{2,}", " ", s))
    return "\n".join(_b2_SIGNOFF.sub("", line).rstrip() for line in s.split("\n"))

def _b2_med_B2code(t):
    return _b2_strip_quote_markers(_b2_split_code_glue(t))

def medicine_b2(text):
    out = _b2_med_B2code(text)
    return ("drop", text) if out is None else out
```

**Action:** fix.

**Harm test:** changes 0 and drops 0 of 26 gold documents (limit 1): **PASS**.

**Side effects:** Repairs two forms only: code statements glued together and e-mail quote markers. Missed: forum timestamps glued to usernames ('10:02 AMdrain'), field labels glued to text ('SystemDate:'), code flattened onto one line where a comment swallows the following code (not repairable). Over-reach: on a line starting '> ', a '>' between two non-math words is removed even if it was a written comparison; a '>' breadcrumb separator at the start of a line is also removed (harmless). Measured on my pack: it acts on 12 of my 106 B2 documents (the rest are misses of the kinds above) and touches 2 documents I did not label B2.

## Medicine 6: C3 (Truncated document)

**Disease:** C3, 65 documents in my pack. Published August 14, 2012.' @25 (abstract text missing)); `2ab919b65e15bf56` ('use the table on the page to show the effect of each transaction. Transactions: 1)...' @2819 (teasers cut with ...)).

**Medicine:** Cut a cut-off teaser at the end of the document: while the last line ends in '...', '…', '. . . .', '(more…)', '[More]', '… Expand', 'more...', 'Read more' or 'Continue reading' (and is not TeX '\ldots'), remove it.

```python
import re
import unicodedata

_c3_C3_TAIL = re.compile(r"(?:\.\.\.|…|\. \. \. \.|\(more…\)|\(more\.\.\.\)|\[More\]|… Expand|\bmore\.\.\.|Read more|Continue reading)\s*\|?\s*$", re.I)

def _c3_med_C3(t):
    lines = t.rstrip().split("\n"); cut = False
    while len(lines) > 1 and _c3_C3_TAIL.search(lines[-1]) and not re.search(r"\\ldots|\$", lines[-1][-12:]):
        lines.pop(); cut = True
        while len(lines) > 1 and not lines[-1].strip():
            lines.pop()
    return "\n".join(lines) + "\n" if cut else t

def medicine_c3(text):
    out = _c3_med_C3(text)
    return ("drop", text) if out is None else out
```

**Side effects:** Can cut only a cut-off teaser at the very end. ## Medicine 7: G4 (Over-normalised: characters deleted)

**Disease:** G4, 63 documents in my pack. Examples: `6134c52da8a58271` ('$r\colon X(n)\to X(n1)$' @400 (minus lost in formula: X(n-1))); `2e2ce9b280e20005` ('quantummechanics' @879 (hyphen lost in prose)); `5def73cfa41a475b` ('h[xi] exp[xi^2/2]' @13220 (minus lost: exp[-xi^2/2])).

**Medicine:** Drop documents where minus signs were deleted inside 2+ TeX formulas ('g^1' for g^-1, 'X(n1)' for X(n-1), 'p^{r1}'): the meaning of the math cannot be restored.

```python
import re
import unicodedata

def _g4_spans(t):
    out, i, n = [], 0, len(t)
    while i < n:
        if t[i] == "\\" and i + 1 < n and t[i + 1] == "$":
            i += 2; continue
        if t[i] == "$" and not t.startswith("$$", i):
            eol = t.find("\n", i); eol = len(t) if eol == -1 else eol
            if i > 0 and (t[i - 1].isalnum() or t[i - 1] == "_"):
                k = t.find("$", i + 1, eol)
                body = t[i + 1:k] if k != -1 else ""
                if not (body and len(body) <= 40 and not body[0].isspace() and (re.search(r"[\\^{]", body) or body[0] == "_")):
                    i += 1; continue                   # R / PHP variable: 'df$degree', 'US$'
                # else a formula glued to the word before it, 'non$C_{k}$spaces': read it as math
            if re.match(r"\$\s?\d", t[i:]) and "$" not in t[i + 1:eol]:
                i += 1; continue                       # money: '$2350', '$7.99 Each' (no closing $ on the line)
        if t[i] == "$":
            disp = t.startswith("$$", i)
            d = "$$" if disp else "$"
            j = i + len(d)
            while j < n:
                if t[j] == "\\" and j + 1 < n:
                    j += 2; continue
                if t.startswith(d, j):
                    break
                if not disp and t.startswith("\n\n", j):
                    break                              # inline math never crosses a paragraph break
                j += 1
            closed = t.startswith(d, j)
            out.append((i, j + (len(d) if closed else 0), t[i + len(d):j], disp, closed))
            i = j + (len(d) if closed else 0)
        else:
            i += 1
    return out

_g4_MINUS = re.compile(r"(?:(?<=[A-Za-z)])|(?<=\{[A-Za-z]\}))\^\{?1\}?(?![\d.])"   # g^{1}, D}^{1}  (not \int_{0}^{1})
                   r"|\^\{[a-z]1\}"                                          # p^{r1}
                   r"|\((?:[a-z])1\)"                                         # X(n1), (x1)
                   r"|\\ldots,\s*[a-z]1\b")

def _g4_minus_lost(t):
    out = []
    for a, b, body, disp, closed in _g4_spans(t):
        if not closed:
            continue
        off = a + (2 if disp else 1)
        for m in _g4_MINUS.finditer(body):
            # '^1' alone right after an integral/sum limit is a real 1, skip it
            if re.search(r"\\(?:int|sum|prod|bigcup|bigcap|lim)\w*_\{?[^}]*\}?$", body[:m.start()]):
                continue
            out.append(off + m.start())
    return out

_g4_G4_MATH_MIN = 2

def _g4_med_G4(t):
    # drop only when minus signs are lost INSIDE formulas (the math now says something else); hyphens lost in
    # prose words ('onedimensional') leave the text readable, so they are labelled but not dropped
    return None if len(_g4_minus_lost(t)) >= _g4_G4_MATH_MIN else t

def medicine_g4(text):
    out = _g4_med_G4(text)
    return ("drop", text) if out is None else out
```

**Action:** drop.

**Harm test:** changes 0 and drops 0 of 26 gold documents (limit 1): **PASS**.

**Side effects:** Drops only when minus signs are lost inside 2+ TeX formulas. Missed: minus signs lost in plain-text formulas ('(1  t)', OEIS g.f. lines), minus replaced by '?', and hyphens lost in prose words, which are labelled but deliberately not repaired (no safe rule: 'nonnegative' is a word, 'nonEuclidean' is not). Over-reach: a real first power written '^{1}' after a letter, or an index written '(n1)', would count. Measured on my pack: it acts on 3 of my 63 G4 documents (the rest are misses of the kinds above) and touches 0 documents I did not label G4.

## Medicine 8: C4 (Two documents joined)

**Disease:** C4, 41 documents in my pack. Examples: `c48ef4c5389f66af` ('associator. To get something associative on the nose' @2508 (StackExchange comment fragments appended)); `6134c52da8a58271` ('2. CMB 2015 (vol 58 pp. 692)' @945 (journal keyword listing of separate abstracts)); `2ab919b65e15bf56` ('Which account of an Azerbaijani demonstration' @4612 (unrelated geography item)).

**Medicine:** Cut StackExchange comment fragments appended after a post: the block starts at the line holding the first comment signature ('– Name Feb 26 '12 at 11:19'); cut only when it is in the last 70% of the document.

```python
import re
import unicodedata

_c4_SIG = re.compile(r"[–—-] [A-Z][\w.'’ -]{1,40}? (?:Jan|Feb|Mar|Apr|May|Jun|Jul|Aug|Sep|Oct|Nov|Dec) \d{1,2}(?: '\d\d)? at \d{1,2}:\d{2}")

def _c4_comment_block(t):
    """(start of the comment block, list of glue offsets) or None"""
    sigs = list(_c4_SIG.finditer(t))
    if not sigs:
        return None
    start = t.rfind("\n", 0, sigs[0].start()) + 1
    glue = [m.end() for m in sigs if m.end() < len(t) and t[m.end()].isalpha()]
    return start, glue, len(sigs)

def _c4_cut_comments(t):
    cb = _c4_comment_block(t)
    if not cb or cb[0] < 0.3 * len(t):          # only a trailing block; never cut most of a document
        return t
    return t[:cb[0]].rstrip() + "\n"

def _c4_med_C4(t):
    return _c4_cut_comments(t)

def medicine_c4(text):
    out = _c4_med_C4(text)
    return ("drop", text) if out is None else out
```

**Action:** fix.

**Harm test:** changes 0 and drops 0 of 26 gold documents (limit 1): **PASS**.

**Side effects:** Cuts only StackExchange comment blocks recognised by the signature '– Name Mon DD 'YY at HH:MM'. Missed: joined journal abstracts, blog comments and pingbacks, search snippets stitched together. Over-reach: if a signature-like line appears in the first part of a post (a quoted comment), nothing is cut (30% rule), but a quoted comment late in a post would be cut with everything after it.
